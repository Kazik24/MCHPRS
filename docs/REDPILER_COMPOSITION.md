# Redpiler composition contract

Ordinary components and instant assemblies share one runtime. Ordinary execution
is chosen from ordinary interactions before optimization; adding a disconnected
assembly must preserve the ordinary network's execution and observations.

Each physical block, entity and memory cell has one owner. Native component
values in packed nodes are binding caches. Assemblies own their geometry, memory,
reset internals and projected consumer channels. A projected channel replaces
ordinary input search; it is not an additional contribution. Assemblies sharing
one channel must merge before lowering, and duplicate ownership is an error.

Boundary deliveries distinguish electrical values, neighbor notifications,
observations and scheduled work. Notifications retain source, target, direction
and delivery order, including callbacks with unchanged strength. Comparator
electrical inputs and analog override precedence remain separate.

Preparation declares the ordinary propagation envelope before execution planning:
response, consumer and external sampling dust belong to ordinary propagation;
assembly geometry, memory and reset internals retain assembly ownership. Logical
responses derive power from certified expressions, including when native callbacks
deliver samples. Physical reads supply native consumer channels through this
declared envelope; they never define assembly memory or response state.

One indivisible delivery captures inputs, computes and commits all resulting
channels, then dispatches notifications. One sampling writer reads one old memory
snapshot; subsequent writers see its commit. Dust intermediate states and
observable geometry phases are separate deliveries. Feedback is event-driven,
including ordinary delays across an assembly; it is not a circuit fixed point.

The coordinator queues sampling batches with actual recipients and captured power.
Potential prepared fanout does not imply a delivered callback. Separate source
actions remain separate batches, even for the same writer. One source's complete
fanout reads its old bank while ordinary dust intermediate states remain live.
Assembly phase deadlines retain FIFO insertion order and run after ordinary
callbacks in the certified piston phase, independently of region indices.

The runtime owns the clock, scheduler and execution phases. Pending work retains
deadline, priority, FIFO order, pending checks and stale-type checks. Assembly
phases follow their certified timing relative to ordinary callbacks and piston
phases; they are not ordinary Normal-priority ticks. Recursive redstone callbacks
use the same ownership dispatcher and cannot run native piston mechanics on
assembly-owned blocks.

Ordinary groups include electrical links, physical dust, neighbor notifications,
observer watches, far comparator inputs and command dependencies. Comparators
and ordinary feedback select exact native propagation. An interaction crossing
ordinary execution strategies enlarges the conservative group instead of
rejecting the circuit. Collapsed graph rewrites apply only to other groups.

Consumers read committed runtime state, including virtual geometry, independently
of display flushes and IO-only operation. Activation constructs and validates
everything before taking interpreter work. Reset restores ordinary blocks and
entities, assembly geometry and hidden dust before exporting pending work once
in scheduler order; repeater aliases retain their pending work.

Mixed execution is admitted only where the assembly boundary can represent the
externally observable notifications and timing. Unsupported piston mechanics
remain scoped admission failures. Candidate analysis and compilation use the
same preparation policy and export capability checks.
