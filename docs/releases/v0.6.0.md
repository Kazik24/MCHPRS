# MROWW v0.6.0

Checkpoint release for Minecraft Java 1.21.5 (protocol 770), before the independent
logical event-executor work.

## Included

- Existing interpreter and compiled Graph execution, including the O1–O5 compiler
  tiers and experimental O6 specializations.
- O6 automatically assumes stable inputs through each instant region's reset;
  no additional flag is required. Instant output timing and required BUD events
  remain part of the execution contract.
- Qualified O6 FPU computation frames reach 40,165 game TPS median across three
  changing-input runs, starting at trigger activation without warm-up and including
  output projection. Six-game-tick cadence and
  same-tick outputs match the accepted benchmark model, with no physical callbacks.
- Qualified O6 COUNTER execution reaches 4.65M game TPS in the execution timer,
  about 4.00M including benchmark recording overhead, across three six-million-tick runs.
- Logical sample, acceptance and publication bindings for ordinary exclusive BUD
  storage pistons, retaining consequential notifications and tick timing.
- Bounded source-equation extraction, constant propagation, output liveness and
  explicit fallback when an optional compilation cannot be completed.
- Graph projection avoids redundant block-storage writes while preserving block
  entity updates.
- Formatting and compilation-warning fixes, with expanded circuit regressions.

## Scope

The new independent instant-region executor is excluded from this release.
Experimental firing-query probes still use Graph events and are not a
kernel-only execution or throughput claim. The ANPU firing-query research probe
has known Main-input mismatches; that prototype is not used by production Graph
execution.

O6 remains experimental. The qualified COUNTER specialization has limited
interpreter-reconstruction coverage; use the established compiler tiers for
general production builds.

Qualified O6 computation frames omit `tellraw` chat diagnostics, including the
FPU's divide-by-zero, infinity and NaN messages. Other command types retain
general execution.

To activate the FPU frame, stop and reset it with the green trigger ON, compile
with `-O6`, then leave the trigger OFF. Compiling with pending physical work
retains the general executor.

## Running

The Windows archive contains `mroww.exe`, the license and README. Run the server
from its own directory; it creates `Config.toml` with defaults. Existing server
configuration and save files are not bundled or modified by the release package.

Other platforms can build from the tagged source with:

```sh
cargo build --release --locked
```
